## What's new

- A redesigned retro control panel with the headphone robot logo and a one-time welcome.
- Installed/latest yt-dlp versions and a manual update button, with clearer retry messages.
- A **Run checks** button that tests both search providers, audio resolution, and audio delivery.

## Reliability improvements

- Better handling of timeouts, failed searches, simultaneous requests, and expired audio URLs.
- Engine updates wait for active yt-dlp work; interrupted requests release processes and connections.
- First-launch downloads are validated and retried, with a full transfer timeout and an improved FFmpeg download source.
- Portable Python stays local, and setup installs the Chromium version required by Playwright.

## Install or upgrade

Download **vdj-companion-0.2.0-windows-x64.zip** below. Close VirtualDJ and stop the existing backend, extract the ZIP into a new permanent folder, then run **START.bat**. Reopen VirtualDJ and select **Online Music → VDJ Companion Source**.

If a track fails to load, use **Run checks** and check for a yt-dlp update in the control panel.

Validated with 50 automated tests, an isolated first-install check on Windows, live search/audio diagnostics, and a user-confirmed VirtualDJ playback check. A separate fresh Windows OS installation has not been tested.

SHA-256 checksum files are included with the downloads.
