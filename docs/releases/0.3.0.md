# VDJ Companion 0.3.0

- Create named setlists, add tracks from the Companion context menu and export M3U8 playlists.
- Download audio for offline playback with queue status, cancel, retry and removal controls.
- Prepare MP4/H.264 videos up to 720p and play them from Downloaded videos.
- Browse Companion tracks from VirtualDJ History without modifying History files.
- Keep the last successful search in Last search, including after restarting Companion.
- Clearly identify plugin context actions with the Companion: prefix.

## Install or update (Windows)

Close VirtualDJ and stop Companion. Extract the Windows ZIP into a new permanent folder and run START.bat. If upgrading, copy the old data/library folder into the new data folder before launching to keep your setlists and downloaded media. Keep the backend running for saved media playback too.

Downloads are limited to 500 MB per file and a 5 GB library. Videos must finish downloading before loading a deck. To reopen the video output, select VIDEO in the mixer and click the Master preview, or choose Video Output > Windowed.

See the included docs/LIBRARY-PREVIEW.md for the full guide. No media is bundled.

Windows search, deck loading, saved audio/video and returning to search results were manually tested. Automated tests cover storage, authorization, history, cancellation and HTTP range playback.
