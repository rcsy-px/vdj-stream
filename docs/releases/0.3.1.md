# VDJ Companion 0.3.1

Windows now has a built-in application updater. When a newer release is available,
close VirtualDJ and click **Install update & restart** in the control panel.
Companion verifies the download, installs the application and plugin, then restarts.

- Keeps setlists, saved audio/video, settings and portable tools.
- Backs up the previous application and plugin, with rollback if installation or startup fails.
- Recovers interrupted updates through the START launcher.
- Stores update logs and backups locally under `.cache/app-update-*`.

## Important: upgrading from 0.3.0 or earlier

Those Windows releases do not contain the new updater. Install 0.3.1 manually once:

1. Close VirtualDJ and stop Companion.
2. Download `vdj-companion-0.3.1-windows-x64.zip` and extract it into a new permanent folder.
3. Copy `data/library` from your old Companion folder into the new `data` folder to retain setlists and downloads.
4. Run the new folder's `START.bat`, then reopen VirtualDJ.

Future updates can be installed using the panel button. Updates always require
your click; they are not installed silently.

Validation: 113 automated tests, a complete local browser-driven update, a real
failed-startup rollback, and a successful manual update rehearsal.

This is a Windows release. The macOS public beta and its updater remain available
separately: [macOS 0.3.0 beta 1](https://github.com/rcsy-px/vdj-stream/releases/tag/macos-v0.3.0-beta.1).
