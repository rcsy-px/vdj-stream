# VDJ Companion for macOS — 0.3.0 beta 1

Public beta for Apple Silicon and Intel, macOS 14 or later. No GitHub account required.

Includes setlists and M3U8 export, offline audio downloads, prepared videos up to 720p, played-track history and Last search. Companion menu actions are clearly labelled.

## Install

Download vdj-companion-0.3.0-beta.1-macos-universal.zip, extract to a permanent folder and run START.command. The launcher installs its own tools and plugin. This beta is not Developer ID signed/notarized, so macOS may require approval through Privacy & Security. Follow docs/MACOS.md for the full walkthrough.

## Update

Existing beta users can check for updates in the control panel, close VirtualDJ, then use Install update & restart. The updater preserves data, including setlists and downloaded media. Keep Companion running while playing saved files. Setup logs and runtime logs are stored locally in data/logs.

## Testing status

This package must pass builds and automated installation tests on Apple Silicon and Intel before publication. Actual VirtualDJ playback on a physical Mac has not been tested by the maintainer; feedback is welcome. Windows equivalents have been manually tested.

The included library guide explains downloads, setlists, video output and limits. No media is bundled.
